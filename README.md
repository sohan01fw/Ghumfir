# 🌍 Ghumfir — Smart Travel Planner ✈️

Ghumfir is a **travel itinerary web app** that helps users **plan trips, manage budgets, add destinations, and take notes** — all in one place. Designed to make trip planning simple, organized, and fun.

---

## 🚀 Features

* 🗺️ **Search & Add Locations** – Find and add destinations with Google Maps.
* 🧭 **Plan Itineraries** – Organize daily travel routes and schedules.
* 💰 **Budget Tracking** – Manage expenses and stay within your travel budget.
* 📝 **Notes & Reminders** – Save important travel details or personal notes.
* 🔐 **User Authentication** – Secure login and session handling.

---

## 🧠 Tech Stack

### 🖥️ Frontend

* **React.js + Vite** ⚡
* **Chakra UI** for modern responsive design
* **React Hook Form** for smooth form handling
* **Axios** for API requests
* **Framer Motion** for animations

### 🛠️ Backend

* **Node.js + Express.js**
* **TypeScript** for scalable code
* **MongoDB + Mongoose** for database
* **JWT & bcrypt** for authentication
* **Express-session & MongoDB store** for secure session management

---

## 🧩 Setup

```bash
# Clone the repo
git clone https://github.com/sohan01fw/ghumfir.git
cd ghumfir

# Run backend
cd backend
npm install
npm run start

# Run frontend
cd ../frontend
npm install
npm run dev
```
